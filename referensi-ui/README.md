# Referensi UI

Satu folder berisi semua hasil. Buka `index.html` untuk daftar lengkap, atau seret seluruh folder ini ke Netlify Drop.

- `01-kido/` — KIDO, 14 layar, EN/BM
- `02-cakap-klasik/` — Cakap versi pertama
- `03-cakap-chunky/` — Cakap dengan layout referensi pizza (21 layar, tombol "Semua layar")
- `04-cakap-5versi/` — 5 versi UI/UX berbeda (`index-1.html` … `index-5.html`)
- `05-gambar-referensi/` — gambar referensi yang dipakai
