# Aturan kerja repo ini

- Jawab pemilik dalam Bahasa Indonesia. Konten Malaysia dalam Bahasa Melayu, konten Indonesia dalam Bahasa Indonesia.
- Untuk semua tugas media sosial (thread, caption, carousel, video, balas komen, DM), baca dulu dan ikuti persis:
  1. `docs/pustaka-belajar/00-sop-utama/SOP-KONTEN-MEDSOS-AUZAN.md` (akun, link, langkah posting)
  2. `docs/GAYA-BAHASA.md` (patokan gaya bahasa dan nada, wajib untuk setiap tulisan)
  3. `docs/pustaka-belajar/CLAUDE.md` dan `README.md` (peta seluruh pustaka)
- Jangan pernah menulis kunci API ke file, repo, atau chat. Kunci disimpan di Network secrets environment cloud.
- Kalau pemilik memberi aturan gaya baru, tambahkan ke `docs/GAYA-BAHASA.md`.
