KEDAI PANTAS / WARUNG CEPAT (game edukasi BM + ID)

Online-kan (Netlify Drop, tanpa koding):
1. Buka https://app.netlify.com/drop
2. Seret SELURUH folder ini (yang ada index.html) ke kotak di laman itu.
3. Tunggu beberapa saat; Netlify beri satu link.

Main di komputer: buka index.html. Folder uji/ dan bukti/ hanya untuk semakan (boleh dipadam sebelum upload).
Parameter ujian: ?benih=NNN (pesanan sama), ?bahasa=ms|id.
Jalankan ujian: node uji/main-penuh.mjs  dan  node ~/.claude/skills/studio-game-web/scripts/main-uji.mjs .
