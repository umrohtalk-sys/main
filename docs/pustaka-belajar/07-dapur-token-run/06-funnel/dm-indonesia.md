# DM Indonesia untuk automation Zernio (GAME, VIDEO, TOOLS)

Teks ini ditulis sahaja. Automation tidak diubah dan tiada DM dihantar.

Pemetaan semasa (mengikut arahan):
- GAME -> demoprompt (https://demoprompt.edugamelabs.com/id)
- VIDEO -> lpvideo (https://lpvideo.edugamelabs.com/id/)
- TOOLS -> lpvideo (https://lpvideo.edugamelabs.com/id/)

Nota: TOOLS dipetakan ke LP Prompt Video. Jika TOOLS dimaksudkan untuk alat atau Prompt Generator, pertimbangkan semula sasarannya (lptoolsid). Ini keputusan pemilik.

Aturan: setiap teks maksimum 300 aksara, pautan terletak dalam teks, Bahasa Indonesia, tiada emoji.

## Balasan publik "cek DM" (6 variasi)

Dipakai sebagai balasan komen di post, bukan di DM. Tiada pautan dalam balasan publik.

1. Makasih sudah komen! Info lengkapnya sudah masuk DM ya.
2. Halo kak, cek DM ya, detailnya sudah saya kirim.
3. Terima kasih! Silakan cek DM untuk linknya.
4. Hai! Cek kotak DM kamu ya, ada info lengkapnya.
5. Makasih kak. Detail lengkapnya ada di DM.
6. Sudah dibalas lewat DM ya. Cek pesan masuk kamu.
