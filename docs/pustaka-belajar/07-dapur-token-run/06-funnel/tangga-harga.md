## 2. Logik setiap langkah

**Demo -> PG Pro.** Pengunjung demo sudah melihat hasil game dan prompt. Langkah seterusnya ialah menawarkan akses penuh untuk menghasilkan sendiri. Harga Rp 99.000 mudah diterima untuk guru dan rendah berbanding mentoring. Automation GAME mengarahkan pengguna ke demo, dan teks DM menyebut galeri sebagai titik awal.

**PG Pro -> Video.** Pembeli PG yang berminat dalam video (automation VIDEO) ditawarkan Prompt Video dengan harga yang sama. Ini mudah dibandingkan dan tidak memerlukan keputusan harga yang berbeza. Lihat catatan TOOLS di bawah.

**Video -> Mentoring.** Mentoring ditawarkan kepada pembeli yang sudah menggunakan produk dan mengalami kesukaran. Harga jauh lebih tinggi, jadi tawaran hanya dibuat selepas pembeli sudah merasai produk. Gunakan WhatsApp dan tanya soalan pemahaman dahulu.

**Mentoring sebagai puncak.** Jangan tawarkan mentoring kepada pengguna demo kerana jurang harga dan komitmen terlalu besar.
