# 30 Prompt Game Kelas: Siap Tempel

Lead magnet untuk guru. Salin satu prompt, tempel ke AI, dan dapat satu folder game web yang boleh dimainkan murid.

## Cara guna

1. Pilih satu prompt daripada 30 di bawah.
2. Gantikan tiga kurungan berikut dengan isi kelas anda:
   - `[KELAS]` contohnya "Tahun 3" atau "Form 2"
   - `[MATA PELAJARAN]` contohnya "Sains", "Matematik", "Bahasa Melayu"
   - `[TOPIK]` contohnya "Kitar air", "Pecahan", "Kata kerja"
3. Tempel prompt ke AI pilihan anda.
4. Simpan hasilnya sebagai folder: `index.html`, `css/style.css`, `js/app.js`.
5. Buka `index.html` di pelayar untuk mencuba. Kemudian muat naik folder itu ke Netlify Drop jika mahu berkongsi dengan murid.

Semak soalan sebelum digunakan di kelas. AI boleh membuat kesilapan fakta. Prompt ini tidak menyediakan bank soal; isi kandungan datang daripada topik anda.
