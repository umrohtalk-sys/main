# Brief — Teka Ejaan Harian / Tebak Kata Harian
- Tahap ketelitian: **standard** (+ ujian logik ketat untuk penilaian petak, kata harian, pautan cikgu)
- Matlamat belajar: mengeja dan memperkaya perbendaharaan kata 5 huruf (BM sekolah rendah / Bahasa Indonesia) dengan maksud kata selepas setiap pusingan.
- Pemain: murid SD Tahun 4-6 / kelas 4-6 SD dan SMP. Bahasa: BM dan ID (butang di menu).
- Gelung: taip kata 5 huruf, enam cubaan; petak tepat (hijau, blok penuh), ada tapi salah tempat (kuning berjalur), tiada (kelabu). Maskot Clawd bereaksi ikut hasil.
- Mod: Kata Hari Ini (ikut tarikh, sama untuk semua murid), Latihan (rawak), Mod Cikgu (senarai kata sendiri -> pautan #kata=).
- Menang/kalah: padan semua huruf dalam 6 cubaan; selepas tamat, kata + maksud + teks petak untuk kongsi (█ ▒ ░).
- Simpanan: localStorage (try/catch): statistik, streak harian, kemajuan hari ini, bunyi.
- Maskot/palet: Clawd ketam oren (SVG sendiri), krim + oren Claude. Tiada emoji, tiada CDN/font luar.
- Original: senarai kata disusun sendiri; hanya konsep "teka kata enam cubaan" diambil.
