Bulat Rebut Wilayah / Bulat Rebut Wilayah: game web statik (BM/ID), tanpa build.
Deploy: seret folder ini ke https://app.netlify.com/drop  (atau buka index.html terus).
Ujian: node uji/logik.mjs | node uji/main-auto.mjs [telefon|desktop] | node ~/.claude/skills/studio-game-web/scripts/main-uji.mjs .
Kawalan: sapu skrin (telefon) atau anak panah / WASD (desktop). P atau Esc = jeda.
Parameter ujian: ?uji=1 (jam maya, dikawal window.__game.langkah(n)), ?seed=N (musuh boleh diulang).
