## B. 5 ide produk (video, app, game)

### P1. Pek Templat Game Kelas AI (Malaysia + Indonesia)
- **Jenis:** Pek templat game (kuiz, pasangan, kedai, jigsaw) + prompt untuk setiap templat.
- **Untuk:** P2 Guru Indonesia TOOLS, P1 cikgu penat.
- **Bentuk:** Fail HTML statik, boleh seret ke Netlify. Dwibahasa BM/ID. Setiap templat ada maskot.
- **Harga cadangan:** Ikut peta-harga: Rp25,000–50,000 (ID) / RM20–40 (MY). Sahkan harga PG semasa sebelum tetapkan.
- **Dasar:** Pembeli TOOLS 15 komen; benchmark ebook Rp25,000–35,000; Wordwall Pro USD7–11.
- **Versi PG:** Ikut skill studio-game-web yang sedia ada.

### P2. Pakej Prompt Pensyarah (Video kuliah + rubrik + soalan)
- **Jenis:** Pek prompt untuk bahan kuliah, rubrik, soalan, dan skrip video kuliah 3 minit.
- **Untuk:** P3 Pensyarah dan calon pensyarah.
- **Bentuk:** PDF + akses Prompt Generator dengan gaya khusus pensyarah. Boleh jadi bahagian kursus.
- **Harga cadangan:** Lebih tinggi dari P1; sasarkan di bawah RM200 (sebanding UNIMAS) untuk tiket awal.
- **Dasar:** 14 dari 16 komen "Nak jadi pensyarah" minat produk.

### P3. Kalkulator "Beban Cikgu Saya" (app percuma, pemimpin prospek)
- **Jenis:** Web app interaktif, 5 soalan tentang beban harian guru; hasil ialah 3 prompt untuk masalah yang dipilih, dengan pautan ke produk.
- **Untuk:** P1 cikgu penat. Tangkap email/WA (melalui kontak WA sedia ada).
- **Bentuk:** Satu HTML, tanpa pelayan. Jika mahu simpan jawapan, gunakan database Artifact (perlu persetujuan).
- **Harga:** Percuma. Monetisasi melalui produk P1/P2.
- **Dasar:** 63 keluhan; RAPOR: reel curhat dan empati menghasilkan tayangan. Tangkap prospek sebelum jual.

### P4. Siri Video "3 Minit Cikgu Aina" (templat video bersiri)
- **Jenis:** Templat video 3 minit dengan kerangka yang sama (hook, masalah, prompt, hasil, CTA TOOLS). Boleh remake untuk setiap topik.
- **Untuk:** P2 Guru Indonesia dan penonton siri Cikgu Aina.
- **Bentuk:** Video HyperFrames atau Remotion mengikut templat sedia ada (video-tipografi-suara). Versi 16:9 dan 9:16.
- **Harga:** Tidak dijual. Ia enjin pertumbuhan dan bawa pembeli P1/P2.
- **Dasar:** Siri Cikgu Aina 15/16 komen TOOLS. Ukur CTA setiap episod.

### P5. Passport Kompetensi AI Guru (game gamifikasi, percuma dengan pilihan premium)
- **Jenis:** Game web dengan 6 peringkat (asas prompt, RPH, kuiz, rubrik, video, game kelas). Setiap peringkat selesai dapat lencana dan sijil digital (tanpa klaim pengiktirafan rasmi).
- **Untuk:** P4 Ketua panitia dan P1 cikgu (tahap kemajuan) dan P3 (kredit kursus).
- **Bentuk:** Game statik HTML, sasaran dua bahasa BM/ID, kemajuan disimpan dalam localStorage (tanpa data peribadi).
- **Harga:** Percuma untuk 2 peringkat; premium RM/Rp untuk peringkat penuh atau lesen sekolah.
- **Dasar:** Latihan KPM dan Kemendikdasmen berskala besar; game ini melengkapi latihan itu dan tidak menggantikannya. Jangan dakwa ia diiktiraf KPM atau Kemendikdasmen.
- **Risiko:** Tiada pengiktirafan rasmi; jelaskan dalam tajuk.

3. P3 Kalkulator (tangkap prospek) jika P1 berjaya.
