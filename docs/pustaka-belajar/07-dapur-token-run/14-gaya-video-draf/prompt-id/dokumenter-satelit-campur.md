# GAYA VISUAL
Gaya campuran tiga lapis: peta satelit berwarna, panel dua sisi, dan kartu cap bergaya dokumen.
- Peta satelit: enam plate (world, base, wide, strait, borneo, kina) dari citra satelit. Setiap plate diproses dengan saturate 1.15, contrast 1.1, brightness 0.86, lalu multiply dengan rgb(222,232,242). Tepi plate dipudarkan ke arah luar, dan bagian utara tanpa data dipudarkan.
- Plate bergerak dengan kamera pelan. Peta hanya bergerak searah dalam satu bagian.
- Latar foto: foto berbingkai diproses blur 14 px, brightness 0.42, saturate 0.7 sebagai latar panel, dengan foto utama di atasnya.
- Warna: merah #E3262C, putih #F4F1EA, emas #FFCC1F, navy #0B1F8F, teal #00A19C, biru muda #33C2FF, biru #4078FF.
- Font: Anton untuk judul, Oswald untuk angka, Old Standard Bold untuk teks cerita, Special Elite untuk cap dan cip ketik mesin.
- Margin tepi 60 px kiri dan kanan, latar bersih.
