# Brief game — Menara Si Bulat (konsep #10 "Jangkaan Tumpukan")

- **Matlamat belajar:** murid menganggar panjang (cm) dan tinggi (m) dengan membandingkan blok dengan pembaris berskala, serta menukar cm ↔ m (120 cm = 1,2 m).
- **Pemain:** SD Tahun 5–6 hingga SMP (MY + ID). **Bahasa:** BM dan ID, butang tukar di menu dan bar atas.
- **Gelung main:** blok bergayut berayun kiri-kanan → ketik/Space/butang "Jatuhkan" → bahagian terkeluar dipotong (menara menyempit) → ketepatan ≤ toleransi = "tepat sempurna" (+bonus, kombo 2+ memulihkan 5 cm lebar).
- **Menang/kalah:** menang bila tinggi menara = sasaran (6–20 lapisan × 10 cm = 0,6–2,0 m) dengan lebar blok sentiasa ≥ minimum tahap (30–40 cm). Kalah bila blok < minimum atau terlepas langsung. Bintang ikut bilangan tepat sempurna.
- **8 tahap:** kelajuan ayunan 1,3→2,7 rad/s, lebar awal 120→90 cm, toleransi 4→2,5 cm.
- **Maskot:** Si Bulat (bulatan biru + topi pembina), dilukis sendiri pada Canvas 2D, 4 mood (senang, gembira, oops, fikir), menunggang blok.
- **Tahap ketelitian:** `standard` (+ `ketat` untuk enjin logik `js/logic.js`).
- **Aset:** tiada luaran; ikon SVG, bunyi Web Audio sintesis, tiada font/CDN.
- **Original:** hanya idea "jatuhkan blok, potong lebihan" diambil; pembaris berskala, sasaran ukuran, lebar minimum, kombo pulih dan semua rupa/maskot milik sendiri.
