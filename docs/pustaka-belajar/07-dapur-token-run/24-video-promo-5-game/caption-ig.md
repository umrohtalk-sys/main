Komen GAME dan saya DM pautan 5 game ini.

5 game matematik baharu untuk murid, semuanya dibina dengan AI.

1. Susun Syiling: menjumlah syiling hingga nilai wang yang tepat
2. Gabung Nombor: tambah, tolak dan darab nombor yang sama
3. Kedai Pantas: mengira harga, diskaun dan baki wang
4. Letus Gelembung: melatih fakta tambah, tolak dan darab dengan pantas
5. Rebut Wilayah: peratus, pecahan dan perpuluhan pada papan
