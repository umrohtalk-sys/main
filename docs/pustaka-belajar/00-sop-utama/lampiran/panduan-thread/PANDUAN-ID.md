# Panduan terjemahan BM → Bahasa Indonesia (thread Threads)

Ubah thread Bahasa Melayu jadi **Bahasa Indonesia santai** yang terasa ditulis orang Indonesia (bukan terjemahan kaku), untuk audiens guru Indonesia. Struktur, jumlah post, nomor, prompt English, dan CTA tetap sama.

## Kata & istilah
- korang → kalian · kita tetap kita · saya tetap saya · nak → mau · tak → nggak/tidak · dah → sudah · kat/dekat → di · lepas itu → setelah itu · meh saya kongsikan → yuk saya bagikan · senang saja → gampang kok · Mudahkan? → Gampang, kan? · Betul tak? → Bener nggak? · Selamat mencuba → Selamat mencoba · Save dulu → Simpan dulu · kongsi → bagikan · cuba → coba · boleh → bisa · buat → bikin/buat · jimat masa → hemat waktu · penat → capek · murid → murid/siswa
- cikgu → guru (Cikgu-cikgu → Bapak/Ibu guru) · ustaz/ustazah KAFA → ustaz/ustazah TPQ · sekolah rendah → SD · sekolah menengah → SMP/SMA · prasekolah → PAUD/TK · Tahun 4 → kelas 4 · lecturer → dosen · student universiti → mahasiswa · ibu bapa → orang tua · orang kerja pejabat → orang kantoran · usahawan kecil → pelaku UMKM · guru novis → guru baru · cikgu Bahasa Melayu → guru Bahasa Indonesia · cikgu sejarah → guru sejarah · cikgu PJ → guru PJOK · pendidikan khas → pendidikan khusus (SLB)
- RPH → modul ajar (RPP) · peperiksaan → ujian · latihan tubi → latihan soal · PdPc → pembelajaran · tuisyen → bimbel/les · kosa kata → kosakata · ringgit → rupiah (hindari angka uang)
- Hook "BANG, MACAM MANA NAK …?" → "KAK, GIMANA CARANYA …?" (tetap HURUF BESAR). "KHAS UNTUK …" → "KHUSUS UNTUK …". "BERHENTI minta …" → "BERHENTI minta …" / "STOP minta …".
- Dalam prompt English: "Malay language" → "Indonesian language"; konteks "Malaysian Year 4" → "Indonesian grade 4".

## Aturan
- Tanpa emoji, tanpa hashtag, tanpa URL. Pakai "kalian"/"Bapak Ibu", jangan "anda".
- Nama produk sama: Prompt Generator, koleksi 29 template game belajar siap main, Prompt Video, kelas Masterclass AI untuk guru, sesi mentoring 1-on-1.
- CTA kata (PROMPT, GAME, VIDEO, TOOLS, NAK) TIDAK diterjemahkan, tapi "NAK" ditulis "Komen NAK" tetap — jangan ubah kata kuncinya.
- Setiap post ≤ 450 karakter.

## Output
Array JSON, format sama seperti input: {"id","judul","hook","posts","cta","tags"}. **id: ganti awalan "tm" menjadi "ti"** (tm0123 → ti0123). Judul, hook, tags juga diterjemahkan.
