Seri carousel Instagram "Guru AI" (@guruai.my) dibangun per hari: Day 1 = "Bikin aplikasi pembelajaran sendiri", Day 2 (2026-09-04) = "Peta Minda Anda Boleh Jadi Apps". Tiap hari = folder baru bertanggal, satu `index.html` standalone.

**Why:** user mengirim materi mentah + satu gambar referensi gaya desain tiap kali, dan mengharapkan kemiripan gaya 100% dengan referensi itu — tapi paletnya TIDAK ikut referensi.

- Selalu dwibahasa Melayu + Indonesia dengan toggle, teks editable di atas slaid, export JPEG 1080×1350 via html2canvas yang di-inline ke dalam file (tanpa CDN).
- Materi diringkas per poin jadi slaid; sertakan panel caption + hashtag.
- Lihat [[feedback-versioned-filenames]] dan [[feedback-netlify-ready-output]].
