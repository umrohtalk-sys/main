Bunyi whoosh/swish ("set set") setiap kali tukar adegan atau benda bergerak mesti BERBEZA: jana set baharu di ElevenLabs untuk setiap video (6–10 variasi prompt: kertas dilibas, kain, udara, zip, kad diseret, dsb.) dan guna variasi lain bagi setiap potongan dalam video yang sama. Jangan pakai `whoosh.mp3` / `whoosh-transisi.mp3` / `sapuan.mp3` lama yang berulang di semua project.
**Why:** user perasan semua video Claude bunyi transisinya sama, rasa template (14 Nov 2026).
**How to apply:** SFX lain (pop, ding, loceng, langkah) boleh pakai ulang dari project lama ([[feedback-musik-sfx-pakai-ulang]]); hanya bunyi transisi/lontaran yang dijana segar dengan prompt unik (durasi 0.5–1 s, murah). Simpan di `sfx/set-*.mp3` folder project itu sahaja, jangan salin ke project seterusnya.
