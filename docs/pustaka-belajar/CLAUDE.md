# Pustaka Belajar Auzan Hasfi / EduGame Labs

Folder ini adalah "otak" kerja Claude Code lokal milik Auzan Hasfi, dipindah ke Claude Code cloud supaya cara kerjanya sama persis. Isinya hanya teks dan data (MD, TXT, JSON, CSV, data bank konten). Gambar, video dan kode game tidak ikut.

## Urutan baca wajib
1. `00-sop-utama/SOP-KONTEN-MEDSOS-AUZAN.md`: aturan kerja media sosial. Ikuti persis untuk semua tugas posting, caption, thread, carousel, video dan balas komen.
2. `01-memori-claude/MEMORY.md`: indeks semua catatan memori, satu baris per catatan. Buka catatan yang relevan sebelum mengerjakan project yang namanya muncul di indeks.
3. `README.md`: peta isi seluruh folder ini.

## Aturan penting
- Jawab pemilik dalam Bahasa Indonesia. Konten untuk Malaysia ditulis dalam Bahasa Melayu, untuk Indonesia dalam Bahasa Indonesia.
- Catatan di `01-memori-claude/` ditulis pada waktu tertentu (lihat tanggal di dalamnya). Kalau isinya bertentangan dengan SOP utama, ikuti SOP utama. Kalau menyebut file atau folder, cek dulu apakah masih ada.
- Path lokal seperti `~/Downloads/...`, `/Users/auzanhasfi/...` dan `localhost:xxxx` hanya ada di laptop pemilik dan tidak ada di cloud. Anggap sebagai catatan sejarah, bukan lokasi file.
- Kunci API (Repliz, Zernio, Apify, ElevenLabs, OpenRouter, Netlify) TIDAK ada di folder ini. Di cloud, kunci harus disimpan sebagai secret atau env, lalu MCP Repliz dan Zernio disambungkan (lihat bagian 0 SOP utama). Jangan pernah menulis kunci ke file, ke repo, atau ke chat.
- Bank konten (`07-dapur-token-run/07-bank-konten/data/`) adalah sumber ide utama untuk thread. Tandai yang sudah terbit di `07-dapur-token-run/25-thread-variasi-afiq/TERBIT.json`.
- Kalau pemilik memberi aturan baru, tambahkan ke SOP utama atau ke catatan memori yang relevan supaya tidak hilang.
