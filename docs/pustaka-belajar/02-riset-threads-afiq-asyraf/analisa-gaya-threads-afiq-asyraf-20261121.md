## 2. Empat format yang dipakai
1. **Tip langkah demi langkah** (penarik follower) — sapaan golongan → "jangan guna X untuk Y saja" → langkah 1-2-3 → postingan sambungan berisi contoh prompt siap salin → penutup "Selamat mencuba."
2. **Bagi prompt** — satu baris pendek ("Boleh try prompt yang saya kongsi ini untuk …") + postingan sambungan berisi prompt bahasa Inggris berstruktur (bertajuk, ada [PLACEHOLDER]).
3. **Jualan PAS (Problem–Agitate–Solution) dalam 4 postingan**
   - P1: HOOK HURUF BESAR dalam bentuk soalan sakit ("NAK … TAPI TAK TAHU …?") + gambarkan masalah: hasil tak kemas, kena ulang prompt, habis masa & kredit.
   - P2: "Sebenarnya …" (pembalikan: boleh mudah kalau tahu caranya) → "Sebab itu saya sediakan [nama produk]."
   - P3: "Dalam platform ini saya dah sediakan:" + senarai 1-2-3, setiap poin = fitur + manfaat + buang keberatan ("walaupun baru nak belajar", "tak perlu pening …").
   - P4: ulang kesakitan dibuang ("Tak perlu buang masa …") → langkah ringkas → "Dapatkan akses sekarang: [link]".
4. **Personal/kepercayaan** — pinned: kenalkan diri, latar belakang (kredibiliti), apa yang dikongsi, terima kasih sebab follow.

## 3. Ciri bahasa
- **Bahasa Malaysia santai campur Inggeris** (code-switching ringan): "especially untuk beginner", "boleh try", "slide", "prompt", "custom instruction". Istilah teknikal dibiarkan dalam English.
- **Kata ganti "korang / kita / saya"** — "kita" dipakai untuk masalah ("slide yang kita nak") supaya pembaca rasa sekumpulan; "saya" untuk menawarkan ("saya sediakan").
- **Penanda lisan**: "meh", "sikit", "Sudahnya", "Sebenarnya", "Tinggal ikut …", "ya".
- **Kalimat pendek–sederhana**, 1 idea per kalimat, perenggan 1–3 kalimat. Tiada emoji dalam isi (emoji hanya di nama/bio). Tiada hashtag.
- **Ayat sakit konkret** (bukan abstrak): berterabur, ulang banyak kali, habis masa dan kredit.
- **Buang keberatan pemula** berulang: "walaupun baru nak belajar", "tak perlu pening fikir dari kosong", "boleh ubah ikut keperluan".
- **Penutup lembut**: "Selamat mencuba.", "Moga … dapat korang manfaatkan ya." CTA jualan tegas tapi satu kali sahaja.
- **Nama tool disebut terang** di kalimat pertama (Gemini NotebookLM, Canva, ChatGPT) — bagus untuk carian & relevansi.

## 4. Struktur hook (templat)
- `Korang yang [golongan] itu jangan guna [tool] untuk [kegunaan biasa] saja. Cuba [cara lain] supaya [hasil lebih besar].`
- `NAK [HASIL] GUNA AI TAPI TAK TAHU [HALANGAN]?`
- `Boleh try prompt yang saya kongsi ini untuk [hasil].`
- `Yang baru follow akaun saya, meh saya kenalkan diri sikit.`

## 5. Ritma posting
- Thread dipecah: postingan pertama hanya hook + 1–3 langkah (berhenti di tengah supaya orang buka sambungan).
- Campuran harian: tip percuma → prompt percuma → jualan, dalam ±10 jam. Nilai dulu, jual kemudian.
- Link tidak di postingan pertama (link ditaruh di postingan terakhir rangkaian / Telegram / beacons).

**Kesimpulan selepas 3 batch (~27 thread):**
1. **"Berhenti minta AI '[perintah malas]'."** ialah formula paling kuat: 805 (infografik), 254 (slaid cikgu), 40 (video). Varian "Korang yang student itu jangan…" = 1.1K. Empat daripada lima postingan teratas guna pola larangan ini.

## 6. Contoh untuk Auzan (gaya yang sama, topik sendiri)
**Tip (BM):**
> Cikgu yang guna Claude itu jangan suruh dia tulis soalan kuiz saja. Cuba suruh dia terus buat game kuiz yang murid boleh main dalam kelas.
> 1. Buka Claude, tulis topik dan tahun murid.
> 2. Minta "buat game kuiz dalam satu fail HTML".
> 3. Klik Preview, terus boleh main.
> ↳ (sambungan) 4. Nak lebih kemas, guna prompt ini: "…". Boleh ubah ikut subjek. Selamat mencuba.

**Jualan PAS (BM):**
> NAK BUAT GAME UNTUK MURID GUNA AI TAPI TAK TAHU NAK TULIS PROMPT?
> Ramai cikgu dah cuba. Tapi game yang keluar tak jalan, butang tak berfungsi, sudahnya kena ulang prompt sampai habis masa.
> ↳ Sebenarnya cikgu boleh dapat game yang siap main kalau prompt dia betul. Sebab itu saya sediakan Prompt Generator.
> ↳ Dalam ini saya dah sediakan: 1. … 2. … 3. …
> ↳ Tak perlu fikir prompt dari kosong. Tinggal pilih, salin, tampal. Dapatkan akses sekarang: [link]

**Versi Indonesia:** ganti "korang" → "kalian", "nak" → "mau", "tak" → "nggak", "boleh try" → "bisa coba", "Selamat mencuba" → "Selamat mencoba".
