● Workbook Mentoring ClaudeCara pakai

Cara memakai workbook ini

  1. Modul 0 wajib. Semua peserta mulai dari Dasar Claude (±35 menit).
  2. Pilih satu modul karya untuk sesi ini: App, Website, Video, atau Carousel (±70 menit). Modul lain bisa dikerjakan sendiri di rumah dengan halaman yang sama.
  3. Kamu yang mengetik. Mentor mendampingi. Tulis prompt dan catatanmu langsung di kotak yang tersedia.
  4. Centang setiap langkah yang sudah selesai. Kalau macet, tulis di "Catatan macet" dan tanyakan saat itu juga.
  5. Tutup dengan Modul 5: rencana 3 karya berikutnya, supaya ilmunya terpakai.

● PanduanPublish ke Netlify
Panduan

Publish app & website ke Netlify (gratis)

Hasil: link namamu.netlify.app yang bisa dibuka siapa saja dari HP.
  1. Unduh file dari Claude. Di panel Artifact, unduh file HTML. Ganti namanya menjadi index.html.
  2. Buat folder di laptop, mis. kuis-pecahan. Masukkan index.html (dan gambar/logo kalau ada) ke folder itu.
  3. Masuk Netlify: buka app.netlify.com, daftar/masuk dengan email atau akun GitHub/Google.
  4. Seret folder ke halaman app.netlify.com/drop (kotak "Drag and drop your site output folder"). Tunggu beberapa detik.
  5. Link jadi. Netlify memberi nama acak, mis. jolly-cake-12ab.netlify.app.
  6. Ganti nama: buka situsnya → Project configuration (dulu: Site configuration) → Change project name → mis. kuis-pecahan-4b. Link menjadi kuis-pecahan-4b.netlify.app.
  7. Cek di HP, lalu bagikan link ke murid / pelanggan / grup WA.

Mengubah isi setelah online

  1. Lampirkan index.html ke Claude: "Ubah hanya [bagian]. Tampilkan file lengkap."
  2. Unduh file baru, ganti file lama di folder yang sama.
  3. Di Netlify: buka situsmu → Deploys → seret folder ke kotak unggah. Link tetap sama.
Hemat kuota. Akun Netlify gratis (dibuat sejak Sep 2025) mendapat 300 kredit/bulan; satu kali publish produksi memakai 15 kredit (±20 kali per bulan). Kalau habis, situs berhenti sampai bulan berikutnya. Kumpulkan beberapa revisi dulu, baru publish sekali.

Website usaha & profil

Hasil: website online dengan tombol WhatsApp yang berfungsi.

2.1 Susunan halaman yang menjual (centang yang dipakai)

  • Bukti: foto asli, testimoni, angka
