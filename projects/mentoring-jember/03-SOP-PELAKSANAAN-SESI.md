# SOP 03 — Pelaksanaan Sesi Mentoring

> Durasi default (usulan, belum diputuskan user): **180 menit** untuk 1 orang, **210 menit** untuk grup 2–5 orang. Urutan sama di cafe maupun Zoom, mengikuti 6 langkah di LP: Kenali → Susun materi → Praktik → Tanya → Online → Bawa pulang.

## 1. Garis waktu sebelum sesi

| Kapan | Tugas mentor | Pesan ke peserta |
|---|---|---|
| Saat bayar | Catat di tracker & kalender; pilih cafe | `/konfirmasi` (SOP 02) |
| **H-3** | Siapkan materi custom: 1 contoh karya bidang peserta, 3 prompt siap isi, file bahan contoh | "Kak, boleh kirim bahannya sekarang? (daftar soal / menu / foto / logo)" |
| **H-2** | Uji semua prompt di akun latihan; pastikan alat paket siap (link Prompt Generator / PG Video) | — |
| **H-1 19.00** | Cek cafe (buka? Wi-Fi? colokan?) atau buat link Zoom | "Besok [jam] di [tempat/link]. Checklist: laptop+charger, akun Claude & Netlify sudah login, bahan siap. Sampai jumpa! 🙌" |
| **H-0 −60 mnt** | Berangkat/siapkan Zoom, isi daya laptop & HP, hotspot cadangan | "Aku sudah di jalan / Zoom sudah dibuka 10 menit sebelum mulai." |

### Checklist tas mentor (cafe)
- Laptop + charger, HP + power bank, **hotspot/kuota cadangan ≥10 GB**
- Terminal colokan (kabel roll kecil) — banyak cafe colokannya terbatas
- Mouse cadangan, flashdisk berisi bahan contoh & app Fundamental offline (bila ada)
- Kartu QR: LP, link alat, QRIS (untuk pelunasan)
- Lembar "Rencana 3 karya berikutnya" (SOP 07 §3) dan pulpen

### Kriteria memilih cafe (Sumbersari / Kaliwates / Patrang)
1. Wi-Fi stabil (uji kecepatan sebelumnya; ≥10 Mbps unggah), ada colokan di meja.
2. Tidak terlalu bising pada jam sesi; ada meja untuk duduk bersebelahan.
3. Mudah dijangkau peserta; parkir aman.
4. Buka sampai minimal 1 jam setelah sesi selesai.
5. Simpan daftar 3–5 cafe favorit yang sudah diuji (kolom di tracker). Contoh kandidat dari ulasan online di Sumbersari dekat kampus (Jl. Mastrip, Tegalboto, Karimata) dan Kaliwates — **wajib dicek langsung**, jam buka dan Wi-Fi sering berubah.

> Peserta membayar minumannya masing-masing (sudah tertulis di LP).

## 2. Rundown 180 menit (1 orang)

| Menit | Langkah LP | Kegiatan | Hasil |
|---|---|---|---|
| 0–10 | 1. Kenali | Kenalan, cek tujuan, isi "Target sesi hari ini" (minat, masalah, proyek, hasil) | Target tertulis |
| 10–20 | — | Cek teknis: login Claude, aktifkan *code execution & file creation* di Settings (perlu untuk Artifacts di akun gratis), login Netlify | Akun siap |
| 20–55 | 2. Materi | **Modul 0 Dasar** (0.1–0.6) dengan contoh bidang peserta; latihan rumus prompt 4 bagian | Prompt pertama |
| 55–60 | — | Istirahat singkat | — |
| 60–130 | 3. Praktik | **Modul utama** (App / Website / Video / Carousel sesuai target) — peserta yang mengetik | Karya draf |
| 130–150 | 4. Tanya | Revisi bertahap, betulkan error, tanya bebas | Karya rapi |
| 150–165 | 5. Online | Unduh file, seret ke Netlify (app/web) atau unduh MP4/PNG (video/carousel); cek di HP | **Link/karya jadi** |
| 165–180 | 6. Bawa pulang | Simpan prompt, isi rencana 3 karya, akses alat paket, foto bersama + izin publikasi, pelunasan | Rencana + testimoni awal |

**Paket All in**: modul utama bisa dibagi (60–100 App/Web, 100–130 Video atau Carousel singkat), atau tawarkan sesi kedua Zoom 60 menit untuk video.

### Rundown grup (2–5 orang, 210 menit)
- Modul 0 bersama (35 menit), lalu tiap orang mengerjakan proyek sendiri.
- Mentor berkeliling tiap 10 menit (rotasi layar), aturan "angkat tangan" lewat chat grup WA sesi.
- Online & penutup diperpanjang jadi 30 menit.
- Bila ada peserta tertinggal, pasangkan dengan teman yang lebih cepat (peer helper).

## 3. Sesi via Zoom (atau Google Meet)

1. Link dikirim H-1; buka ruang 10 menit sebelum mulai.
2. Peserta **share screen** sepanjang praktik; mentor share screen hanya saat demo.
3. Minta peserta pakai headset; matikan notifikasi.
4. Rekam sesi **hanya dengan izin**, dan kirim rekaman ke peserta saja.
5. Paket Zoom gratis membatasi durasi rapat — pakai akun berbayar atau siapkan link lanjutan (atau Google Meet) untuk sesi 3 jam.
6. Istirahat 5 menit setiap ±60 menit (mata & jaringan).

## 4. Rencana cadangan (masalah yang sering terjadi)

| Masalah | Tindakan |
|---|---|
| Kuota Claude gratis habis di tengah sesi (batas pemakaian bergulir per ±5 jam) | Pindah ke pekerjaan yang tak butuh Claude (Netlify, susun bahan, caption) sambil menunggu; atau lanjut di akun mentor dengan izin lalu file dipindah ke peserta; jadwalkan 30 menit lanjutan via Zoom |
| Artifact tidak muncul | Cek Settings → fitur code execution & file creation aktif; mulai chat baru; perpendek prompt |
| Wi-Fi cafe mati | Hotspot mentor; kalau tetap gagal pindah cafe terdekat / lanjut Zoom malam |
| Laptop peserta lambat/rusak | Pakai laptop mentor dengan akun peserta (logout setelah selesai) |
| Netlify: kredit akun gratis habis | Akun baru (sejak Sep 2025) mendapat 300 kredit/bulan, satu deploy produksi = 15 kredit (±20 deploy/bulan); lewat batas situs ditangguhkan sampai bulan berikutnya. Ajarkan menggabungkan revisi sebelum deploy |
| Karya belum selesai | Catat sisa langkah, lanjutkan lewat WA/Zoom 30 menit dalam 7 hari (gratis) |
| Peserta telat >30 menit | Durasi tetap sesuai jadwal awal kecuali slot berikutnya kosong |

## 5. Setelah sesi

| Kapan | Tugas |
|---|---|
| H+0 malam | Kirim: ringkasan sesi, semua prompt yang dipakai (teks), link karya, akses alat, lembar rencana 3 karya |
| H+1 | Unggah konten "Karya peserta hari ini" (dengan izin) |
| H+3 | Minta testimoni (SOP 07 §4) |
| H+7 | Cek progres + tawaran upgrade (SOP 02 §8) |
| H+14 | Tawaran referral |
| H+30 | Undang grup alumni / sesi lanjutan; label Alumni |

## 6. Standar kualitas sesi (dinilai sendiri setelah tiap sesi, skala 1–5)
1. Peserta pulang dengan karya **online/terunduh** (wajib 5).
2. Peserta yang mengetik ≥70% waktu praktik.
3. Contoh & latihan dari bidang peserta.
4. Peserta bisa menjelaskan rumus prompt 4 bagian.
5. Peserta punya rencana 3 karya berikutnya.

Kalau ada skor ≤3, tulis satu perbaikan di tracker kolom `catatan_mentor`.

## 7. Perawatan LP & alat (mingguan)
- Buka LP di HP: tombol WA, harga, peta, video berjalan.
- Cek kredit Netlify semua situs (LP Jember, LP 1-on-1, LP bidan).
- Pastikan link alat (Prompt Generator, PG Video, app Fundamental) masih bisa dibuka.
- Perbarui angka bukti & foto alumni di LP sebulan sekali (edit `js/data.js`/`index.html` di folder versi terkini → deploy).
